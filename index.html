เชื่อมต่อ Google Sheets Database

จัดการการเชื่อมต่อฐานข้อมูล Google Sheet เพื่ออ่านและแก้ไขข้อมูลแบบเรียลไทม์

https://docs.google.com/spreadsheets/d/1zr9Qtek4BK24wZg1hWh0s0Ui9WGtcP7H3GNJ8ba5kwQ
กรอก URL ที่ได้จากการกด Deploy Web App ใน Google Sheet
ขั้นตอนติดตั้ง Google Apps Script (ทำเพียงครั้งแรก)
  1. เปิดไฟล์ Google Sheet -> คลิกเมนู ส่วนขยาย (Extensions) -> เลือก Apps Script
  2. เปิดไฟล์ google_apps_script.js ในโฟลเดอร์โปรเจกต์นี้ คัดลอกโค้ดทั้งหมดไปวางใน Code.gs บน Apps Script
  3. กดปุ่ม บันทึก (Save / รูปแผ่นดิสก์)
  4. กดปุ่ม ทำให้ใช้งานได้ (Deploy) มุมขวาบน -> เลือก การทำให้ใช้งานได้ใหม่ (New deployment)
  5. คลิกไอคอนเฟืองเลือกประเภทเป็น เว็บแอป (Web app)
  6. ตั้งค่า ผู้มีสิทธิ์เข้าถึง (Who has access) ให้เป็น ทุกคน (Anyone) -> กดปุ่ม Deploy
  7. ให้สิทธิ์อนุมัติ (Authorize access) แล้วคัดลอก **Web App URL** มาวางในช่องด้านบนแล้วกดบันทึก
